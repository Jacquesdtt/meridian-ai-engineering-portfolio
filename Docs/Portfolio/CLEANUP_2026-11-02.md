unclosed-connection warnings no longer appear. Queue inserts reserve the writer

last observed timestamp, so a stale edit cannot overwrite an approval or a newer
edit.

without a recognised percentage marker still require human review. PII filtering
does not prove a provider retention policy.

cloud and model evidence remains historical. Public publication uses a normal
