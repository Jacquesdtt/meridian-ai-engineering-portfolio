Quick PowerShell Execution & Troubleshooting

  • One-Click Launcher: Run .\launch_all.ps1 in PowerShell to verify or launch all 3 background services simultaneously.
  • Run Backend: uv run python -m uvicorn src.serving.app:app --port 8000
  • Or run Backend in Docker: docker compose up -d --build (set API_PORT=8001 if a host API already uses 8000)
  • Run Friction Gate: uv run python -m streamlit run Code\Sprint3\friction_gate_app.py --server.port 8501
  • Run Educational Tour: cd educational_web_app; npm run dev:portal
  • Run Full Tests: uv run --with pytest python -m pytest tests -q (127 passed, 2026-09-24) & cd educational_web_app; npm test
